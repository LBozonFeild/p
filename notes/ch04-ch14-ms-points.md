# How marks are awarded (always)

- Correct final answer with no working still gets **full marks**, unless the question says *show your working*.
- **ECF** (error carried forward) is used: a wrong value used correctly later still scores later marks.
- **Do not round until the final answer.** Intermediate rounding can lose the last mark.
- If a unit is not a separate mark, a missing or wrong unit on the final calculated answer usually **loses the last mark**.
- Equations: **multiples / fractions of coefficients are accepted** unless the MS forbids them.
- **State symbols are ignored** unless the question asks for them (or the MS says otherwise).
- Spellings of syllabus terms must be unambiguous (`ethane` / `ethene`, `sulfate` / `sulfite`).
- Contradictory statements in the same part: **no credit** for the correct one.
- List questions (“state two…”): extra wrong answers still count towards *n*; only the first *n* non-contradictory answers are marked.

**Units they expect**

- Amount: `mol`
- Mass: `g` (or `kg` if given)
- Molar mass: `g / mol`
- Volume of gas at r.t.p.: `dm3` (or `cm3` if the paper uses cm³)
- Concentration: `mol / dm3` **or** `g / dm3`
- `cm3 → dm3`: divide by **1000**
- `dm3 → cm3`: multiply by **1000**

**Constants they credit**

- Avogadro constant = **6.02 × 10²³** particles per mole
- Molar gas volume at **r.t.p.** = **24 dm³** = **24 000 cm³**

## 4.1 Formulae

### Definitions (write these)

- **Molecular formula:** the number and type of different atoms in **one molecule**.
- **Empirical formula:** the **simplest whole-number ratio** of the different atoms **or ions** in a compound.

### Deducing formulae from ion charges

Write the formula so that **total positive charge = total negative charge**. Swap charges and simplify.

**Cations (must know)**

| ion | formula |
|---|---|
| hydrogen | H⁺ |
| lithium / sodium / potassium / silver | Li⁺ / Na⁺ / K⁺ / Ag⁺ |
| ammonium | NH₄⁺ |
| magnesium / calcium / barium / zinc / iron(II) / copper(II) / lead(II) / nickel(II) | Mg²⁺ / Ca²⁺ / Ba²⁺ / Zn²⁺ / Fe²⁺ / Cu²⁺ / Pb²⁺ / Ni²⁺ |
| aluminium / iron(III) / chromium(III) | Al³⁺ / Fe³⁺ / Cr³⁺ |

**Anions (must know)**

| ion | formula |
|---|---|
| hydride / fluoride / chloride / bromide / iodide / hydroxide / nitrate / hydrogencarbonate / manganate(VII) | H⁻ / F⁻ / Cl⁻ / Br⁻ / I⁻ / OH⁻ / NO₃⁻ / HCO₃⁻ / MnO₄⁻ |
| oxide / sulfide / sulfate / sulfite / carbonate | O²⁻ / S²⁻ / SO₄²⁻ / SO₃²⁻ / CO₃²⁻ |
| nitride / phosphate | N³⁻ / PO₄³⁻ |

**MS examples they always want correct**

- sodium chloride → NaCl
- magnesium oxide → MgO
- calcium chloride → CaCl₂
- aluminium oxide → Al₂O₃
- aluminium chloride → AlCl₃
- sodium sulfate → Na₂SO₄
- calcium carbonate → CaCO₃
- ammonium sulfate → (NH₄)₂SO₄
- ammonium nitrate → NH₄NO₃
- iron(II) sulfate → FeSO₄
- iron(III) chloride → FeCl₃
- copper(II) sulfate → CuSO₄
- potassium manganate(VII) → KMnO₄
- calcium phosphate → Ca₃(PO₄)₂
- magnesium hydroxide → Mg(OH)₂
- aluminium sulfate → Al₂(SO₄)₃
- sodium carbonate → Na₂CO₃
- sodium hydrogencarbonate → NaHCO₃
- zinc nitrate → Zn(NO₃)₂
- lead(II) bromide → PbBr₂

**Common MS trap:** oxidation number in the name **must** match the formula (`copper(II)` is Cu²⁺, not Cu⁺).

### Word / symbol / ionic equations

Marks split is almost always:

- **correct formulae of reactants and products** (1)
- **balancing** (1)
- **state symbols** (1) — **only if asked**

If they ask for an **ionic equation**:

- show **only the ions / molecules that change**
- **leave out spectator ions**
- include state symbols if asked: `(s)` `(l)` `(g)` `(aq)`

**Ionic equations that score repeatedly**

- acid + alkali: `H⁺(aq) + OH⁻(aq) → H₂O(l)`
- acid + carbonate: `2H⁺(aq) + CO₃²⁻(aq) → CO₂(g) + H₂O(l)`  (or `H⁺ + HCO₃⁻ → CO₂ + H₂O`)
- precipitation of a chloride: `Ag⁺(aq) + Cl⁻(aq) → AgCl(s)`
- precipitation of a sulfate: `Ba²⁺(aq) + SO₄²⁻(aq) → BaSO₄(s)`
- precipitation of a hydroxide, e.g. `Cu²⁺(aq) + 2OH⁻(aq) → Cu(OH)₂(s)`
- metal + acid, e.g. `Mg(s) + 2H⁺(aq) → Mg²⁺(aq) + H₂(g)`

**State-symbol MS rules**

- metal, insoluble salt, precipitate → `(s)`
- water as liquid product → `(l)` (not `(aq)`)
- gases (H₂, O₂, CO₂, NH₃, Cl₂, SO₂) → `(g)`
- acids, alkalis, soluble salts in solution → `(aq)`
- molten ionic compound (electrolysis) → `(l)`

**Balancing MS rule:** if they ask for **state symbols**, the formulae must already be correct or the state-symbol mark is often **dependent**.

## 4.2 Relative masses

### Definitions (write these)

- **Relative atomic mass, Aᵣ:** the **average mass of the isotopes** of an element compared to **1/12 of the mass of an atom of ¹²C**.
- **Relative molecular mass, Mᵣ:** the **sum of the relative atomic masses** (covalent substances).
- **Relative formula mass, Mᵣ:** used for **ionic compounds** — still “sum of the relative atomic masses”.
- MS also accepts **molar mass** for Mᵣ in calculations.

### Aᵣ from isotopes (almost always 2 marks)

```
Ar = ((%₁ × mass₁) + (%₂ × mass₂) + …) / 100
```

- **M1** correct numerator (each abundance × its mass, all added)
- **M2** divide by 100 / correct denominator

If abundances are given as **fractions / decimal proportions** that already add to 1, **do not divide by 100**.

**MS phrases**

- isotopes have **the same number of protons** but **different numbers of neutrons** / different mass number / different nucleon number
- isotopes have **the same chemical properties** because they have the **same number of electrons** / **same electronic configuration**

## 4.3 The mole and the Avogadro constant

### Definitions (write these)

- The **mole, mol**, is the unit of **amount of substance**.
- **One mole contains 6.02 × 10²³ particles** (atoms / ions / molecules / electrons). This number is the **Avogadro constant**.
- **Concentration** can be measured in **g / dm³** or **mol / dm³**.

### Core relationships (every calculation paper)

```
amount (mol) = mass (g) / molar mass (g / mol)

mass (g) = amount (mol) × molar mass (g / mol)

molar mass (g / mol) = mass (g) / amount (mol)

number of particles = amount (mol) × 6.02 × 10²³

amount (mol) = number of particles / 6.02 × 10²³

amount of gas (mol) = volume (dm³) / 24
                    = volume (cm³) / 24 000

volume of gas (dm³) = amount (mol) × 24

amount (mol) = concentration (mol / dm³) × volume (dm³)

concentration (mol / dm³) = amount (mol) / volume (dm³)

concentration (g / dm³) = concentration (mol / dm³) × Mr
```

**MS conversion they always want**

- volume in cm³ → dm³: **÷ 1000**
- 25.0 cm³ = **0.025 dm³**
- 250 cm³ = **0.250 dm³**

## 4.4 Calculation methods — how the marks are split

These mark splits are what Papers 1 and 2 actually use. Learn the **steps**, not the numbers.

### A. Mass ↔ moles ↔ particles

Typical 2 marks:

- **M1** moles = mass / Mᵣ   **or** moles = particles / 6.02 × 10²³
- **M2** mass = moles × Mᵣ   **or** particles = moles × 6.02 × 10²³

### B. Reacting masses (stoichiometry)

Typical 3 marks:

- **M1** moles of the **given** substance = mass / Mᵣ
- **M2** moles of the **required** substance using the **mole ratio from the equation**
- **M3** mass of required = moles × Mᵣ

**MS phrase for the ratio step:** “moles of X = (coefficient X / coefficient Y) × moles of Y”

### C. Gas volumes at r.t.p.

Typical 3 marks:

- **M1** moles of given = mass / Mᵣ   **or** volume / 24
- **M2** moles of gas using the mole ratio
- **M3** volume = moles × 24 (dm³)

**Equal volumes of gases** at the same T and P contain **equal numbers of moles** (Avogadro’s law). Volumes are **in the same ratio as coefficients**.

### D. Concentration of solutions

Typical 3 marks:

- **M1** moles of known solute = conc × (volume in cm³ / 1000)
- **M2** moles of unknown using the mole ratio
- **M3** conc of unknown = moles / (volume in cm³ / 1000)

**g / dm³ ↔ mol / dm³**

- g / dm³ = mol / dm³ × Mᵣ
- mol / dm³ = (g / dm³) / Mᵣ

### E. Titration calculations (Paper 2 theory — method of working)

Same 3-mark pattern as D. Extra MS points:

- use the **mean titre** (concordant values only — that is a Paper 3 recording rule; in Paper 2 they give you the volume)
- **mole ratio from the balanced equation** is a separate mark
- final concentration usually to **3 significant figures** if they ask

**Worked MS skeleton (acid + alkali)**

```
moles of alkali = conc × vol/1000          (1)
moles of acid   = moles of alkali × (acid coeff / alkali coeff)   (1)
conc of acid    = moles of acid / (vol of acid / 1000)            (1)
```

### F. Empirical formula

Typical 2–3 marks. Table they credit:

| element | % or mass | ÷ Aᵣ | mole ratio | simplest ratio |
|---|---|---|---|---|

- **M1** divide each % (or mass) by the correct Aᵣ  → number of moles
- **M2** divide **all** mole values by the **smallest**
- **M3** write the empirical formula (whole numbers)

**MS wording they actually use**

- “division by correct relative atomic mass”
- “division by lowest value to get correct answer”
- “correct number of moles”
- “empirical formula = …”

If the ratio is not whole (e.g. 1 : 1.5), **multiply through** (×2 → 2 : 3). That still scores M2/M3.

If they give **mass of oxygen by difference**:

- mass of O = total mass − masses of other elements   (1)
- then the usual mole-ratio steps

### G. Molecular formula from empirical formula

Typical 2 marks:

- **M1** Mᵣ of the empirical formula
- **M2** n = (given Mᵣ) / (empirical Mᵣ)  → molecular formula = (empirical)ₙ

**MS phrase:** “molecular formula has the same ratio as the empirical formula but Mᵣ = …”

### H. Percentage composition by mass

Typical 2–3 marks:

```
% of element = (Ar × number of atoms of that element / Mr of compound) × 100
```

- **M1** correct Mᵣ
- **M2** correct expression / unrounded value
- **M3** answer to the required sf / dp (if they ask, often 1 d.p. or 3 sf)

Used a lot for **fertilisers** (% N in NH₄NO₃, (NH₄)₂SO₄, CO(NH₂)₂, etc.).

### I. Percentage yield

```
percentage yield = (actual mass / theoretical mass) × 100
```

Typical 2–3 marks:

- **M1** theoretical moles / theoretical mass from the equation (reacting-mass method)
- **M2** % yield = actual ÷ theoretical × 100

### J. Percentage purity

```
percentage purity = (mass of pure substance / mass of sample) × 100
```

Typical 2–3 marks:

- **M1** moles of **pure** substance from titration / gas volume / reacting mass
- **M2** mass of pure = moles × Mᵣ
- **M3** % purity = (mass pure / mass of impure sample) × 100

**MS phrase:** “mass of pure X in the sample”

### K. Limiting reactant

Typical 2–3 marks:

- **M1** moles of **each** reactant
- **M2** compare with the **equation ratio** → identify which is limiting
- **M3** moles / mass / volume of product from the **limiting** reactant only

**Phrases that score**

- named solid is the **limiting reagent** / the other reagent **is in excess**
- amount of product is **proportional to the mass of the limiting reagent**

### L. Water of crystallisation (hydrated salts)

For MX · xH₂O:

```
Mr (hydrated) = Mr (anhydrous) + 18x
x = moles of water / moles of anhydrous salt
```

Typical 2–3 marks:

- **M1** moles of anhydrous salt **and** moles of water
- **M2** x = mole ratio water : salt
- **M3** formula e.g. CuSO₄·5H₂O

Heating to constant mass (the **idea** appears in Paper 2; the practical is Paper 3):

- mass of water lost = mass before heating − mass after heating
- heat to **constant mass** so **all water of crystallisation is removed**

### M. Deducing Mᵣ from titration / gas data

Typical 3 marks:

- **M1** moles of the **other** reagent (from conc × vol or V/24)
- **M2** moles of the unknown using the ratio
- **M3** Mᵣ = mass / moles

## 4.5 Equations you must be able to use in calculations

These keep appearing as the **equation the numbers hang on**. Balancing is a mark; using the **correct ratio** is the next mark.

**Combustion**

- complete: hydrocarbon + O₂ → CO₂ + H₂O
- incomplete: hydrocarbon + O₂ → CO + H₂O   **or** C + H₂O
- MS phrase for incomplete combustion: **combustion in a shortage / limited supply of oxygen**

**Metals**

- metal + oxygen → metal oxide
- metal + acid → salt + hydrogen
- metal + water (Group I / steam) → hydroxide or oxide + hydrogen
- metal + salt solution → more reactive metal displaces

**Acids**

- acid + base → salt + water
- acid + carbonate → salt + water + carbon dioxide
- acid + alkali → salt + water
- acid + metal oxide → salt + water
- acid + metal hydroxide → salt + water
- acid + ammonia → ammonium salt

**Common industrial / syllabus equations used in mole questions**

- `N₂ + 3H₂ ⇌ 2NH₃`
- `2SO₂ + O₂ ⇌ 2SO₃`
- `CaCO₃ → CaO + CO₂`
- `CaO + H₂O → Ca(OH)₂`
- `C + O₂ → CO₂`  and  `2C + O₂ → 2CO`  and  `C + CO₂ → 2CO`
- `Fe₂O₃ + 3CO → 2Fe + 3CO₂`
- `2NaHCO₃ → Na₂CO₃ + CO₂ + H₂O`

## 4.6 Paper 1 (MCQ) facts that are the mark

These are the statements that make the **correct option**. Wrong options are usually a ratio error, a cm³/dm³ error, or using 24 with a solid.

- 1 mole of **any gas** at r.t.p. occupies **24 dm³** (same volume for H₂, O₂, CO₂, NH₃…).
- 1 mole of **atoms / molecules / ions** contains **6.02 × 10²³** of those particles.
- 1 mole of O₂ contains **2 × 6.02 × 10²³ oxygen atoms** (because O₂ is diatomic).
- Number of **molecules** in 24 dm³ of any gas at r.t.p. is the same; number of **atoms** depends on whether the gas is monoatomic / diatomic / etc.
- Empirical formula is **not** always the molecular formula (molecular = n × empirical).
- Same **empirical** formula does **not** mean same **molecular** formula (CH₂O vs C₆H₁₂O₆).
- Concentration **doubles** if volume is halved at constant moles (or moles double at constant volume).
- Mixing equal volumes of 1.00 mol / dm³ solutions does **not** give 2.00 mol / dm³ — moles add, volume adds.
- % yield uses **masses of the same product** (actual vs theoretical), not masses of reactant unless they are equivalent by the equation.
- For gases in an equation, **coefficients = volume ratio** at the same T and P.
- Water of crystallisation: heating **decreases mass**; the residue is the **anhydrous** salt.
- Mᵣ of an ionic compound is **relative formula mass** (not “molecular mass” in the strict definition, but Mᵣ is still used).

## 14.2 Acid–base titration method (recurring ≤3-mark points only)

Not the mole calculation (that is Chapter 4).

- place **alkali in the flask** and **acid in the burette** (or the reverse if they specify)
- add until the **indicator changes colour** / **end-point** / **neutralised**
- **repeat using the same volumes but no indicator** (to make the salt)
- then **evaporate to crystallisation point** / heat until **saturated**, **cool**, **dry** (filter paper)

**Concordant titres (Paper 3 written, 1–2 marks)**

- concordant = within **0.20 cm³**
- mean from the **concordant / ticked** values **only**
- repeat to check results are **consistent / reproducible**

**Heat loss (Paper 3 written, 1–2 marks)**

- measured temperature change is too small because of **heat loss** (to surroundings)
- improvement: **lid** / **insulation** / **polystyrene** cup

## 14.3 Chromatography (recurring ≤3-mark points only)

- chromatography **paper dipping into the solvent**
- **spot / origin / base line above the solvent level**
- **pencil** not pen / ink: **ink will run** / ink **separates** / ink undergoes chromatography / **pencil will not run**
- **locating agent** to **make the spots visible** / because the spots **may not be coloured** / substances are **colourless**
- locating agent is used **after** the run

```
Rf = distance travelled by substance / distance travelled by solvent
```

- **pure:** **one spot** / a **single Rբ**
- **mixture / impure:** **more than one spot**
- same substance: **same height** / **same Rբ**
- identify an unknown by **comparing with a known** (same paper or matching Rբ)

## 14.4 Separation and salt preparation (recurring ≤3-mark points only)

**Which method (the name is the mark)**

- insoluble solid + liquid → **filtration**
- soluble salt from its solution → **crystallisation**
- N₂ and O₂ / liquid air / ethanol + water / petroleum → **fractional distillation**
- water from aqueous copper(II) sulfate / water from dissolved salts → **(simple) distillation**
- dissolved coloured substances → **chromatography**
- salt + sand → dissolve, **filter**, then crystallise the filtrate

**Fractional distillation — write these**

- **fractional distillation** / **fractionating column**
- **different boiling points**
- liquid air: **liquefy / heat / vapourise** the air, then fractional distillation
- petroleum: **heated / vapourised / boiled**, then separated because of **different boiling points**
- (fractions with) **lowest boiling point come off at the top** / highest at the bottom / fractions come off at **different levels** in the column

**Simple distillation — write these**

- depends on **boiling point** / copper(II) sulfate (or salts) has a **higher boiling point than water**
- flask connected to a **condenser**
- flask / solution **heated** — only **water vapourises**
- water vapour converted to liquid water **in the condenser** / salts **left in the flask**

**Insoluble salt (precipitation)**

- mix two **aqueous solutions**
- **filter**
- **wash and dry the residue** (not crystallise the filtrate)

**Soluble salt from acid + insoluble base / carbonate / metal**

- add **excess** solid (to **warm** acid)
- **filter** (collect the **filtrate**) — removes **excess / unreacted solid**
- **filtrate evaporated to crystallisation point** / heated until **saturated**, then **left to crystallise** / **cool**
- **wash and dry** crystals with **filter paper**

**Why excess solid?** so **all the acid is used up**

**Why filter?** to **remove the excess** (undissolved) solid

**MS crystallisation phrases (same wording, many papers)**

- evaporate to **crystallisation point**
- heat until **saturated** (solution formed)
- leave / **cool** / leave in a **warm place** and **filter** / **dry**
