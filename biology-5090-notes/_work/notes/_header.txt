HOW TO READ THESE NOTES
-    each line that begins with a dash = one separately creditable marking point taken from official mark schemes / answer keys.
/    separates accepted alternative wordings for the same mark.   ( ) words in brackets are not required for the mark.
Accept: / Reject: / Ignore:  examiner guidance attached to that point.   ORA = or the reverse argument.   AW = alternative wording accepted.
"max n" = no more than n marks were available from that list in the question concerned.
Context:  explanatory sentence added to make a point understandable; it is NOT itself a mark-scheme statement.
Where newer and older mark schemes genuinely conflict the newer wording is given first and the older one is marked "older mark schemes".
Paper / question references are kept in full_paper_verification_tracker.txt, not here.
